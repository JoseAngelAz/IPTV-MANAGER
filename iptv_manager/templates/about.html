{{ tr.guia_paso_a_paso_para_operar_el_sistema }}

{{ tr.primeros_pasos }}

  1. {{ tr.iniciar_sesion_title }} — Ve a /accounts/login/ e ingresa tus credenciales.
  2. {{ tr.dashboard }} — Al entrar verás el panel principal con indicadores clave: clientes activos, suscripciones vigentes, ingresos del mes, y gráficos financieros.
  3. {{ tr.mi_perfil }} — En "Mi Perfil" puedes agregar tu foto, nombre completo y correo electrónico.
  4. {{ tr.personalizar_tema }} — En "Personalizar Tema" elige entre 5 presets o crea tu propio esquema de colores.

{{ tr.gestion_de_clientes }}

  1. Crear cliente — Ve a Clientes → Nuevo Cliente. Ingresa nombre, teléfono, email y dispositivo (MAC address).
  2. Agregar foto — Al crear o editar un cliente puedes asignarle una foto de perfil.
  3. Ver detalle — Haz clic en un cliente para ver su información completa, suscripciones activas, historial de cambios y notas.
  4. Agregar notas — Desde la ficha del cliente puedes añadir notas internas visibles para todo el equipo.
  5. Editar/Eliminar — Usa los botones de acción en la lista de clientes. Solo roles con permisos pueden eliminar.

{{ tr.suscripciones_y_planes }}

  1. Crear suscripción — Ve a Suscripciones → Nueva Suscripción. Selecciona un cliente, un plan, y la fecha de inicio.
  2. Planes disponibles — Los planes se configuran en el admin de Django. Cada plan tiene nombre, precio y duración en días.
  3. Estados — Las suscripciones pueden estar: activas, vencidas o canceladas. El sistema calcula automáticamente la fecha de vencimiento.
  4. Renovar/Cancelar — Usa los botones de acción en la lista para renovar o cancelar suscripciones existentes.
  5. Historial automático — Cada cambio en una suscripción se registra automáticamente en el historial del cliente.

{{ tr.finanzas }}

  1. Ver movimientos — En Finanzas verás el listado completo de ingresos y egresos.
  2. Registrar movimiento — Usa "Nuevo Movimiento" para registrar un ingreso (pago de suscripción) o egreso (gasto operativo).
  3. Dashboard financiero — El panel principal muestra gráficos de ingresos vs egresos de los últimos 6 meses, con proyecciones.
  4. Nota: Solo roles con permisos financieros pueden crear o modificar movimientos (el rol Soporte solo puede ver).

{{ tr.notificaciones }}

  1. Ver notificaciones — En Notificaciones se listan todos los envíos realizados.
  2. Enviar recordatorio — Desde la ficha de un cliente o suscripción puedes enviar recordatorios manuales.
  3. Recordatorios automáticos — El sistema tiene un comando cron que envía recordatorios de suscripciones por vencer.
  4. Canales: WhatsApp y correo electrónico, según la configuración del cliente.
  5. WhatsApp API: El sistema incluye un microservicio Node.js (whatsapp-api/) que se conecta a WhatsApp Web. Al iniciarlo por primera vez, muestra un código QR que debes escanear con tu WhatsApp. La sesión queda guardada para usos futuros. Detén y reinicia el contenedor si necesitas cambiar de cuenta.
  6. Resolución de errores WhatsApp: Si ves Error al enviar WhatsApp con "Connection refused", verifica que el servicio esté corriendo: docker-compose ps whatsapp o docker-compose logs -f whatsapp.

{{ tr.actividad }}

  1. Ver actividad — En Actividad se registra automáticamente cada acción del sistema (crear, editar, eliminar, login, logout).
  2. Filtrar — Usa los filtros de acción, modelo y fecha en el admin de Django para búsquedas avanzadas.
  3. Eliminar registros — Solo el admin maestro (superuser) puede eliminar registros, individualmente o en lote.
  4. Selección múltiple: Marca varios registros con checkboxes y usa "Eliminar seleccionados".

{{ tr.personalizacion }}

  1. Temas predefinidos — Elige entre 5 presets: Moderno, Corporativo, Minimalista, Vibrante y Dark Neumorphic.
  2. Colores manuales — Personaliza cada color individualmente con selectores de color.
  3. CSS personalizado — Agrega tu propio CSS para ajustes finos adicionales.
  4. Presets guardados — Guarda tus combinaciones favoritas como preset personalizado con nombre e icono.
  5. Modo oscuro — Activa/desactiva desde el interruptor en la barra lateral.

{{ tr.tareas }} (To-Do List)

  1. {{ tr.nueva_tarea }} — Crea tareas personales con título, prioridad y categoría.
  2. {{ tr.prioridad }} — Asigna prioridad: Baja, Media, Alta o Urgente. Las tareas se ordenan automáticamente.
  3. {{ tr.categoria }} — Clasifica por categoría: General, Clientes, Finanzas, Suscripciones, Sistema, Otro.
  4. Fecha de vencimiento — Opcionalmente asigna una fecha límite. Las tareas vencidas se marcan en rojo.
  5. Completar/Eliminar — Marca como completada haciendo clic en el checkbox o elimínala con el botón de borrar.
  6. {{ tr.filtros }} — Filtra por estado: Todas, Pendientes o Completadas.

{{ tr.solucion_de_problemas }}

No puedo iniciar sesión

Verifica tus credenciales. Si excediste los intentos, espera 1 hora o contacta al administrador.

No veo algunas secciones

Tu rol de usuario determina qué secciones puedes ver. Contacta al admin maestro si necesitas más permisos.

El servidor no responde

Asegúrate de que el servidor esté corriendo con python manage.py runserver. Verifica que el puerto 8000 esté libre.

No se ve el sidebar

En dispositivos móviles el sidebar se oculta automáticamente. Toca el botón de menú (☰) en la esquina superior izquierda para mostrarlo.
